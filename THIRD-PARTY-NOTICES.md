# Third-party notices

This product's own code is under the license in [LICENSE](LICENSE). Its release bundles also include the
third-party components listed here, each under its own license.

- Each Java library ships as its unmodified jar, which carries its own license file and NOTICE file under
  `META-INF/`. Their NOTICE files are repeated below, and a license text appears below only for a jar that carries none.
- The web interface's packages are bundled into minified JavaScript, CSS and fonts that keep no license files, so
  their copyright lines and license texts appear in full below.
- Skills from other authors ship as their own folders under `skills/`.
- Other third-party files ship beside their license file, which is named below.

Generated by `./gradlew thirdPartyNotices`, which the release build runs, so the copy in a bundle matches what that
bundle ships. Do not edit it by hand: record what a component cannot say for itself in `gradle/third-party-licenses.json`.
