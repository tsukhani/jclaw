Callable JClaw API endpoints (143). Invoke one by calling this tool with method + path (and body for mutating verbs); endpoints not listed here are operator-only and will be refused.

- DELETE /api/conversations/{id}/model-override - Clear a conversation's model override, reverting to the agent default (idempotent)
- DELETE /api/conversations/{id}/pin - Unpin a conversation (idempotent)
- DELETE /api/conversations/{id}/star - Unstar a conversation (idempotent)
- DELETE /api/conversations/{id}/thinking-override - clear thinking override
- DELETE /api/mcp-servers/{id} - Disconnect and delete an MCP server by id
- DELETE /api/prompts/{id} - Delete a prompt by id
- DELETE /api/scrape-jobs/{id} - Delete a scrape job that is not waiting or running, its page records and its workspace folder

- DELETE /api/subagent-runs/{id} - Delete a terminal subagent run with its transcript and the agent it spawned
- DELETE /api/tasks/{id} - Hard-delete a task by id along with its runs, messages, notifications, and scheduler row

- POST /api/tasks/{id}/run - Fire a task immediately by id, reviving a CANCELLED task first so the run isn't skipped
